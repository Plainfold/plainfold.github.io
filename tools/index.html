Data tools · for businesses, researchers and AI agents

Small data tools, priced per result.

For AI agents

Your agent can find these tools, run them and pay per result.

  1. Add the remote MCP server (streamable HTTP) to Claude, Cursor, VS Code or any MCP client. All 4 tools:https://mcp.apify.com/?tools=plainfold/sam-gov-contract-opportunities,plainfold/business-entity-check,plainfold/company-hiring-signals,plainfold/sec-company-financials
  2. Sign in with a free Apify account (OAuth), or send Authorization: Bearer <APIFY_TOKEN>. Agents without an account can pay per use with x402 or Skyfire through Apify.
  3. Ask your question. Runs are billed per result at the prices above. One tool only: https://mcp.apify.com/?tools=plainfold/<tool-slug>
